# XA401のSITから現在番組を取得する

2026-11-15、利用者がスマホで映像・音声を再生できた後、「番組情報がありません」の表示を報告。原因は初版のBridgeが`/api/programs`を空配列としていたことだった。

XA401の部分TSには通常のEIT（PID 0x12）がなくても、**SIT（PID 0x1f、table_id 0x7f）に現在番組の情報が含まれる**と実サンプルで確認した。EITがないことから番組情報全体がないとは判断できない。

## 取得するもの

- 放送ID記述子（0x85）：元のネットワークID・TSID・イベントID。
- パーシャルTSタイム記述子（0xc3）：実際の開始時刻・放送時間。オフセットも適用する。
- 短形式／拡張形式イベント記述子：番組名・説明・出演者など。
- コンテント記述子：ジャンル。

新しい`epg.py`はTSの連続性・pointer fieldを扱い、CRCが正常なSITだけをARIBライブラリへ渡す。元のサービスID・NID・TSIDが選択したチャンネルと一致しない情報は採用しない。開始時刻・継続時間が不明なら架空の時刻を補完しない。

解析は元のTSを読むだけで、映像・音声・CCIを書き換えない。Mirakurunの`isFree`は放送CAの分類で、Copy FreeやDTCPの出力許可という意味ではない。

## 実測

NHK総合の受信から、イベントID 15050、開始12:15、継続45分、終了13:00の番組を取得できた。KonomiTVの`/api/channels`でも現在番組の名称・開始・終了・イベントIDを確認した。これはDMSの番組名から時刻を推測した結果ではなく、SITに記述された値である。

別プロセスで既存のTSサンプルを解析した確認と、Bridgeの実受信経路で取得した確認を分けて記録した。原データと詳細結果は調査リポジトリ側のローカル`runs/epg-sit-20261115/`へ保持し、映像・生パケットをGitHubへ配布しない。

## 表示される範囲

視聴中にSITを受け取ったチャンネルの現在番組を蓄積するほか、`epg_collection.enabled`を有効にすると、**視聴していない間に各局を短時間ずつ受信して現在番組を収集する**。未視聴の局が一覧で空欄になる問題に対応した。未来の番組や全チャンネルの週間番組表は生成しない。次番組の情報はSITだけでは取得できない。

収集も同じPCのDTCP受信エンジンを使い、1局ずつ実行する。既定例では1局10秒以内、局間に2秒以上を空け、地デジ→BS→ケーブルの順で初回収集する。正確な現在番組を受け取ったらすぐ切断する。映像ファイルは保存しない。失敗した局は5分から最大1時間まで間隔を延ばし、連続して接続しない。視聴中は別局の収集を行わず、別局への視聴要求が来たら収集用接続を閉じて視聴を優先する。

取得した番組の終了時刻、または10分後に再取得対象とする。放送終了直後の更新には収集とKonomiTVの取込み分の遅れがある。未契約・配信不可・時刻情報がない局は空欄のままになるため、全局の情報取得を保証しない。1局視聴中に全局を並行取得する機能ではない。

```json
"epg_collection": {
  "enabled": true,
  "types": ["GR", "BS", "CS"],
  "timeout_seconds": 10,
  "interval_seconds": 2,
  "refresh_seconds": 600
}
```

設定例は有効。設定を省略した既存環境では無効のままで、明示的に有効化する。`CS`はXA401の再多重化ケーブル一覧を含む（KonomiTV上ではCATVに分類される場合がある）。`/health`の`epg_collection`で試行・成功・視聴による中断数を確認できる。診断APIもloopback限定。

KonomiTVの`general.program_update_interval`を`0.5`（30秒）に設定した。初めて選ぶチャンネルでは、受信開始後に情報が取り込まれるまで更新間隔分の待ちがある。観測したキャッシュは機器UDNへ紐づけてローカル保存し、違う機器のものを引き継がない。

## 検証とライセンス

追加テストは、SITの実時刻・ID・タイトル、複数TSパケットへの分割、重複、CRC不正、異なるサービス、時刻未記載、機器別キャッシュ、期限切れを対象とする。収集では視聴優先の中断・同局共有・失敗時の間隔・実SIT観測を成功条件とすること・キャンセル時の受信解放も検査する。計30テスト成功。人工データのテストを実放送の受信成功とは数えない。

実機では、未視聴のNHKサブチャンネル・Eテレ等のSIT取得を確認。さらに別局の収集中にNHK総合への視聴要求を出し、収集のpreemptedが1増え、HTTP 200でTS 4,096/4,096パケットの同期を確認した。詳細な収集範囲とKonomiTVへの反映結果は調査側の実測記録に残す。

ARIB構造と文字列はariblib 0.2.0の公開wheel（MIT）を使用し、ライセンスを同梱した。KonomiTVのAGPLソースをこの独立アプリへコピーしていない。
