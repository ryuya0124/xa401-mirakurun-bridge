# 録画・予約とXA401の直接再生

管理入口は `/api/xa401/recordings`。KonomiTVのPWAが有効な環境でも開ける。
PC録画は設定で明示的に有効化し、保存先・FFmpeg・ffprobeを指定する。
日時指定の予約を永続化し、受信後にTSとデコードを検証して公開する。
XA401側の録画予約・削除・ダビング・Moveは実行しない。

XA401録画の一覧はDMS Browse、直接再生は原画質のDTCP-IP受信を用いる。
PCファイルの事前保存は不要。総時間はDIDLのduration、再生位置は
DLNA TimeSeekRangeを使用する。HTTP byte Range対応とは区別する。
放送配信と合わせ最大2枠。録画や視聴を背景EPG収集より優先する。

2026-11-15の実機検証：録画144件を列挙。0秒・600秒・1790秒から
受信し、各32768個のTS同期を確認。先頭と600秒の映像・音声デコード成功。
利用者がスマホで映像・音声と、後半・終盤へのシークを確認した。
90秒のPC予約録画は約87.9秒のTSとして保存され、全AVデコード成功。
このPC保存分はKonomiTV標準の録画一覧にも登録された。

シークで同じプレイヤーとWorkerを再利用し、直前のフレームを次のフレームまで
画面内メモリーで保持する。ページやvideo要素を作り直さない。
Media Sessionに録画タイトル・固定総時間・現在位置を渡し、OS側のシーク操作も受け付ける。
これらのコード／世代競合テストは成功。スマホOS上の表示・ちらつきの実確認は未了。

XA401録画をKonomiTV標準録画一覧・標準プレイヤーへ統合する作業は継続中。
現状の独立管理画面を、標準UI統合済みとは扱わない。
